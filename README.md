# Priority Pilot

Priority Pilot is a lightweight task triage dashboard that helps small teams decide what to do next when everything feels urgent.

## Problem statement

Small teams lose time and momentum when incoming requests, bugs, and follow-up work all compete for attention without a shared prioritization method.

## Solution

Priority Pilot scores each task by impact, urgency, and effort, then ranks the backlog so the next best action is obvious.

## Run it

Open `index.html` in a browser.

## What it does

- Ranks tasks with adjustable scoring weights
- Shows the highest-priority task and explains why it wins
- Lets you add new tasks and re-score the queue instantly
- Includes a demo backlog you can load with one click
